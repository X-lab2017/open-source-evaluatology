# Contributing / 参与共建

This is a public review draft, not the final published edition. Please report errata, methodological questions, reproduction results, or documented cases through Issues. Include the chapter/section, exact passage or figure, evidence, and proposed correction. Do not upload confidential datasets or personal information.

本项目为公开评审预览版。欢迎通过 Issue 提交勘误、方法讨论、复现结果与有据可查的案例。请注明章节、原文或图号、证据与建议，不上传机密数据或个人信息。

The LaTeX files in `manuscript/` are canonical. Do not maintain an independent web copy of chapter prose. Bibliographies are chapter-specific. The site chapter guide is derived from those files.

**Do not commit PDFs**, archives, generated build output, font binaries, credentials, or temporary review files. Build locally when needed. Preserve authorship and third-party source notices. Submit changes through a focused pull request; publication approval belongs to the authors.

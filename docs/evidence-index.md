PDF figure dependencies are distributed as SVG. `manuscript/pdf-figure-manifest.json` records original PDF SHA-256 values and the converted source paths. Original PDFs are not distributed. Captions preserve the scholarly attribution; conversion does not change third-party rights.

The book source retains conceptual illustrations as illustrations, not empirical results.
